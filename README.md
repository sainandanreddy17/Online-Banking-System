\# Online Banking System



\## Project Description

The Online Banking System is a simple web-based application designed to manage basic banking account information. It demonstrates Git and GitHub collaboration practices, including branching, merging, and manual conflict resolution.



\## Modules

\- Account Management

\- Account Details

\- Account Balance Management

\- Account Type Management



\## Technologies Used

\- HTML

\- Git

\- GitHub



\## Git Operations Performed

1\. Initialized a Git repository.

2\. Created the Account Management module.

3\. Created separate feature branches.

4\. Modified the same file in different branches.

5\. Created a merge conflict intentionally.

6\. Identified and resolved the conflict manually.

7\. Committed the resolved changes.

8\. Verified the final Git history.



\## Merge Conflict Details

A merge conflict was created when two feature branches modified the same section of the Account Management module.



The conflict was resolved manually by combining the required changes from both branches and committing the final version.



\## Conclusion

This project demonstrates Git branching, merging, conflict creation, and manual conflict resolution using an Online Banking System scenario.
